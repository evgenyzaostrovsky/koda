# Ответы помощника направлений — 2026-10-22

Без публикации. Пары вопросов/сырых ответов автоматически сохраняются в `Goal.roadmapClarifications` и существующем JSON целей `user_app_state`. Новых таблиц и миграций нет. Ответ можно исправить или удалить в помощнике. Пустой ответ сохраняется пустым; подстановка «не знаю» выполняется только в запросе. После открытия окна с ответами выбран полный роадмап. ИИ получает до восьми актуальных пар, возвращаемых новых вопросов по-прежнему максимум два.

Применимость связана с id, названием и ожидаемым результатом цели. Изменение времени, режима, прогресса и дополнение planningContext не сбрасывают ответы. Изменение названия/результата делает прежние пары неактивными; данные остаются в истории. Старый клиент без поля не стирает ответы. Сохранённые ответы входят в fingerprint запроса: изменение во время генерации делает предложение устаревшим.

Merge объединяет отдельные операции по вопросам. Удаление/очистка сохраняют tombstone; функциональные React updater при одинаковом входе и captured timestamp детерминированы. На вопрос хранятся восемь версий, показываются восемь последних активных пар. При одновременном редактировании одного ответа выбран детерминированный вариант, другие недавние значения остаются в данных. UI отдельной истории вариантов пока нет. Общего лимита на старые questionId/версии названия цели нет: это ограничение роста истории при длительной эксплуатации.
