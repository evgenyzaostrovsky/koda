# Карта цели и предложения AI — локальная проверка

Дата: 2026-10-21. Без публикации и изменения рабочих записей пользователя.

## Изменения

- По умолчанию цель и восемь направлений; полная сетка 9×9 доступна отдельно.
- Направление и пустой слот открывают редактор поверх карты; существующее действие открывает свой редактор.
- Центр цели и кнопка «Помочь с направлениями» открывают предложения для существующей цели.
- Контекст и время относятся к одному подходу. Предложения редактируются и добавляются только после подтверждения.
- Добавление сохраняет существующие действия, ID, прогресс и историю; не меняет главный результат цели.
- Устаревшие ответы после закрытия/смены цели игнорируются. Изменение исходной цели блокирует применение устаревших предложений.

## Проверено

Изолированное гостевое превью localhost:8098, Supabase отключён, API localhost:3337 с Яндексом. Только тестовая цель «Стать Data Analyst».

- Открытие редактора направления; создание ручного шага.
- Исправлено потерянное название направления в вебе: сохранение по onBlur; переход к другому полю обновляет карту и историю.
- Центр открывает AI. Реальный ответ Яндекса: три направления с шагами на 5–10 минут.
- Название предложения изменено, третье направление удалено, оставшиеся добавлены; ручной шаг сохранился.
- После обновления страницы добавленные направления и действия восстановились.
- В полной карте пустой слот открывает соответствующее направление, заполненный — редактор действия.
- Исправлена раскладка компактной карты на широком экране: три столбца вместо пяти.

Автоматические проверки: test:open-window (включая test-goal-structure) — прошли. Проверяют отсутствие дублей, сохранение прогресса/ID, атомарный отказ при заполненных слотах, архивные направления и JSON-восстановление. Итоговая веб-сборка экспортирована; раскладка 3×3 проверена скриншотом, название «База анализа» сохранилось после повторного обновления страницы. Typecheck повторён после последней правки раскладки.

Независимый QA просмотрел код без записи: конкретных дефектов после исправлений не обнаружил. Это проверка кода, не отдельный браузерный прогон. Физическое мобильное устройство в этой задаче не проверялось.
