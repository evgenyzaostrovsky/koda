# Желание → главная цель → направления

Локальная доработка 2026-10-21, без публикации.

В мастере создания цели AI доступен с первого шага. Он предлагает короткое название главной цели и желаемый результат. После подтверждения оба поля можно уточнить, затем отдельно запросить направления с первыми шагами. AI не добавляет структуру без подтверждения и не меняет принятую формулировку при добавлении направлений. Можно создать цель с одним направлением или без них, расширив карту позже.

API возвращает необязательное goalTitle, сохраняя совместимость со старыми ответами. Промпт запрещает выдумывать сроки, доход, объём и подменять главный результат первым шагом. Обычный старт ограничен тремя направлениями с одним шагом в каждом; при ограниченном ресурсе предлагается одно направление.

Черновик v1 совместим с прежними данными; новое название хранится отдельно от желания. Закрытие, переходы и изменение исходных полей инвалидируют AI-ответы. Отмена подтверждения смены главной цели сохраняет черновик.

Проверки: test:goal-ai и итоговый typecheck прошли; итоговая веб-сборка экспортирована. Независимый QA проверил исходники и выявил потерю черновика при отмене смены главной цели; исправлено, повторный просмотр не выявил конкретных дефектов.

Браузер, изолированное гостевое превью localhost:8098 и реальный Яндекс через API3337:

- Желание: попробовать аналитику данных, оценить интерес, мало сил, подходы по 15 минут без ежедневного режима.
- AI предложил «Ознакомиться с основами аналитики данных», результат — понять, подходит ли эта работа. Пользовательская правка названия принята.
- Следующий запрос дал одно направление и один шаг на 15 минут. Предложения добавлены явно, пустое второе направление удалено.
- Создана главная цель с одним направлением и одним действием, без срока; после обновления цель и шаг восстановились.
- Отмена подтверждения замены главной цели сохранила черновик на последнем шаге. Повторное открытие восстановило название, результат и структуру; подтверждение затем создало цель. Следующее открытие мастера показало пустой новый черновик.
- При временно недоступном локальном API мастер показывал ошибку, не подставляя фиктивного ответа. После запуска сервера вне сетевой изоляции реальные запросы прошли.

Рабочие записи пользователя не изменялись; публикации не было. Физическое мобильное устройство не проверялось.
