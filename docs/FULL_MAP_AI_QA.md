# Полная карта от главной цели

Добавлен добровольный режим «Заполнить всю карту» в помощнике направлений существующей цели. По умолчанию остаётся «Небольшой старт». Полный режим запрашивает восемь направлений с восемью действиями; архивные слоты сохраняются и исключаются из заполнения. Все архивные направления: локальная подсказка восстановить направление.

Перед добавлением показан редактируемый черновик со свёрнутыми группами и счётчиками. Сохранение только явной кнопкой. Главная цель, результат, существующие действия, идентификаторы и прогресс сохраняются; повторное добавление не создаёт дублей. Безымянное направление с работой получает название при точном сохранении его действий.

Проверено 2026-10-22:
- npm run typecheck, npm run test:open-window, npm run test:goal-ai — PASS.
- Живой Яндекс: синтетическая цель аналитика, 8×8, исходный desiredResult сохранён.
- Браузер, изолированное локальное превью 8098: выбор полного режима, живой ответ 8 направлений / 64 шага, явное добавление к тестовой цели с одним существующим действием, обновление страницы — восстановлены все восемь групп по восемь действий, главная цель и результат прежние.
- Независимая статическая QA: найден случай всех архивных направлений, добавлена локальная подсказка.

Сетевое ограничение среды: стандартный Node DNS дал UND_ERR_CONNECT_TIMEOUT; повтор с NODE_OPTIONS=--dns-result-order=ipv4first успешен. Локальный API запущен с этим параметром, ключи не менялись.
