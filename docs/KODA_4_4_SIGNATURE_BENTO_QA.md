# KODA LIFE 4.4 — Signature Bento UI

24 октября 2026. Локальная реализация, без публикации.

## Эталон цели

Сначала реализован и просмотрен экран цели на 1440×900 и 390×844. По первому просмотру уменьшены текстовые факты, исправлено пересечение описания с вырезом, мобильные факты собраны по два в ряд. По следующему просмотру исправлены разрывы линии маршрута и несовпадающий статус раскрытого текущего этапа. Только после этого изменены композиции остальных разделов.

Главная карточка: насыщенный лайм, результат, фактический прогресс, текущий этап, релевантное действие или предложение добавить его, компактный маршрут. Рядом — только факты, для которых есть данные. Четыре этапа размещаются горизонтально; длинная последовательность имеет собственную прокрутку. На телефоне узлы соединены вертикально. Раскрытый этап показывает реальные задачи, описание, срок и существующие инструменты управления. ОТАНИ сохраняет отдельную вкладку и полное окно 9×9.

Контур рисует существующий NotchedWidget: неинтерактивный SVG, измеряемая область, плавный вогнутый участок и отдельная круглая кнопка контекста. На телефоне используется обычная скруглённая карточка. Изображения-референсы использованы как направление композиции; фотографические фоны и фиктивные метрики не добавлены.

## Продуктовые исправления

1. nextRoadmapAction выбирает доступное действие только текущего этапа. Если оно отложено, заблокировано зависимостью или отсутствует, более поздняя задача не подставляется. У цели без этапов сохраняется выбор из доступных действий цели. Расчёт прогресса не менялся.
2. Создание действия из пустого текущего этапа предвыбирает этот этап. Выбор в форме больше не ограничен первыми двумя этапами.
3. В деталях текущий статус берётся из фактического прогресса и положения в маршруте, а не только из сохранённого not_started.
4. Завершённые цели можно снова открыть из списка после обновления. Статус завершения не подменяет фактический процент этапов.

## Остальные разделы

- Планнер: дневной список и быстрый ввод — основной инструмент; календарь и ближайшие датированные дела — боковые модули. Удалены лишние счётчики. На телефоне обзор остаётся ниже основных дел. Исправлены промежуток колонок и минимальная ширина управления датой.
- Привычки: дневной итог и неделя выровнены по общей строке; крупные интерактивные отметки. Пауза, редактирование и архив раскрываются через «Параметры». История отметок и вычисления серий сохранены.
- Прогресс: компактный график с реальной последней оценкой за показанный период, соседние метрики, объяснение SCORE и отдельный список активных целей. Даты графика различимы в двухнедельном диапазоне. При малой истории нет выдуманной кривой.
- Проекты: убран ряд крупных счётчиков; библиотека показывает прогресс, ближайшие задачи и открытие проекта. Единственный простой проект не занимает половину пустой сетки.
- Заметки: первый абзац больше не вложен в декоративную карточку; панель действий компактнее. Библиотека, поиск и редактор сохранены.
- Дневник: видимая кнопка истории и компактные дополнительные параметры.
- Помощник: быстрые запросы над перепиской; сообщения и поле ввода сохраняют полезную ширину и высоту.
- Таймер и профиль: сохранены удачные композиции и функции. Рабочий стол и «Мой день» не перестраивались.

## Система и файлы

Сохранены ограничения содержимого: 1040 — стол/день/планнер, 960 — цели/прогресс, 880 — привычки/проекты, 840 — заметки/чат, 800 — дневник, 760 — профиль, 640 — таймер. Desktop gap24, compact16, внутренние отступы20–24; сетка minmax(0,1fr). MetricCard получил отдельный размер значения для текстовых фактов. Короткие состояния нажатия, поверхности, прогресса и появления цели учитывают prefers-reduced-motion.

- theme.ts; также scripts/test-refinement41-data.ts, DESIGN.md и этот отчёт.

В рабочей копии сохранены изменения прежних итераций. Общий git diff не следует считать diff только 4.4.

## Ограничения

- Проверка размеров браузера не равна проверке физических iPhone/Android, Safari, экранной клавиатуры и VoiceOver.
- Новые запросы к живому AI и новый прогон Supabase между двумя физическими устройствами не выполнялись. Хранилище и схема в этой итерации не изменялись; автоматические проверки изоляции и синхронизации прошли.
- Пользовательские иконки привычек автоматически не переназначаются по названию. Датированная история таймера не выдумана: используется имеющийся счётчик.
- Оценка завершения цели и процент её этапов — разные сохранённые факты; вручную завершённая цель может иметь незакрытые этапы.
- Снимки используют локальные тестовые записи. Некоторые дополнительные снимки фиксируют этап визуальной проверки; основные desktop/mobile показывают интегрированную версию.
- Публикация не выполнялась.
