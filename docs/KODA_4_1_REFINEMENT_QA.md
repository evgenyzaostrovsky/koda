# KODA LIFE 4.1 — локальная реализация и проверка

Дата: 2026-10-23. Публикация не выполнялась.

## Реализовано
- Планнер: ближайшие реальные даты, отдельные просроченные/недатированные, исключение привычек и завершённых, устойчивый выбор новой версии дубликата. Переход из виджета сохраняет дату и источник в адресе.
- Быстрый ввод: относительные даты, корректный заглавный «Завтра», проверка невозможных дат/времени.
- Цели: интерактивный путь, текущий этап, описания, сроки, действия, перестановка. Следующее действие предпочитает текущий этап; переход в направление OTANI открывает конкретную ячейку.
- Привычки: именованные иконки, цвет, архив/восстановление, история 30 дней, сохранение дат паузы и независимое слияние метаданных. Изменения используют существующее хранилище, без миграции.
- Прогресс: повторный ID действия не увеличивает процент; архивирование цели не стирает достигнутое. Недельная статистика привычек использует реальные даты и расписание.
- SCORE: календарные промежутки, различение отсутствия итога, активного дня, старой формулы и настоящего нуля, выбор дня. Формула и исторические значения не изменены.
- Мобильный рабочий стол: планнер на всю ширину, новая исходная последовательность, компактные SCORE/фокус, настройки виджетов только на рабочем столе; поиск в меню раздела.
- Старт: короткий экран бренда с пропуском и reduced motion, фраза «Маленькие шаги к большим изменениям».

## Подтверждено
- test:widgets: базовый desktop, 10 habit, 9 data и 14 planner suites прошли.
- Независимый QA воспроизвёл возврат старого незавершённого дубликата. Исправление подтверждено регрессионным тестом.
- Итоговый `npm run typecheck` и `npm run check:encoding` прошли.
- Итоговый локальный audit export прошёл: `index-994d5f6630da75496abd7060ddcf3e3e.js`.

## Ограничения
- Три попытки открыть webview встроенного браузера завершились тайм-аутом подключения; список вкладок пуст. Визуальные проверки семи размеров, виртуальной клавиатуры и новые скриншоты 4.1 не выполнены. Старый архив 4.0 не является доказательством версии 4.1.
- Офлайн/два владельца проверены моделированием существующего протокола. Live Supabase, физические устройства и переключение реальных аккаунтов не проверялись, рабочие данные не менялись.
- Старые привычки без записанной истории пауз/изменений расписания не позволяют восстановить неизвестные прошлые события.
- Полный `npm test` завершился с кодом 0.

Обычный export в dist и тест offline shell завершились с кодом 0. Audit и обычный export получили одинаковое имя bundle; работу авторизации и переключение audit-флага в браузере подтвердить не удалось. Перед публикацией необходима проверка обычного экрана входа.
