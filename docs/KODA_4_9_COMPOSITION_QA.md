# Композиция рабочего стола — 25 октября 2026

Локальная доработка без публикации. Существующие данные пользователя не изменялись.

## Что изменилось

В стандартной desktop-композиции планнер уплотнён с 239 до 190 px: компактные заголовок и строки, при наличии предупреждений меньше превью ближайших дел. Полный список по-прежнему доступен в планнере. Заметки сужены с 670 до 467 px; длинный заголовок и текст ограничены в превью, исходное содержимое не обрезается в данных. Планнер получил освободившуюся ширину.

Средний ряд теперь имеет единую высоту 190 px; под SCORE и заметками устранён дополнительный провал 49 px. Нижний ряд начинается через 20 px. Фактические размеры при viewport 1440×1000:

Для пользовательского порядка desktop включается плотная упаковка CSS Grid с измерением высот через ResizeObserver. Сохраняются ширины и естественная высота карточек; более поздние карточки могут занимать свободное место выше. На телефоне действует обычная сетка без этого режима. При произвольной перестановке фиксированных размеров отдельные пустые области всё ещё возможны; обещание полного заполнения каждого пикселя не даётся.

Листья растения округлены, прожилки приглушены, фоновые силуэты смягчены. Размер иллюстрации и цитаты сохранён. Это доработка SVG, не точная растровая копия.
