# Модули KODA

Папка для экранов MVP и логики фич. Визуальный стиль должен следовать утвержденным макетам.

План модулей:

- `auth`: вход по email и Google, состояние авторизации.
- `onboarding`: утвержденный онбординг, разговор с ИИ, выбор сфер жизни, создание будущей версии.
- `dashboard`: главный дашборд из утвержденных web/mobile макетов.
- `futureSelf`: карточка будущей версии, XP и уровень.
- `attributes`: финансы, здоровье, дисциплина, карьера, отношения, эмоциональная устойчивость.
- `goals`: создание, редактирование и удаление целей.
- `quests`: ручное создание квестов, создание из целей, выполнение.
- `reflect`: записи рефлексии и инсайты от ИИ.
