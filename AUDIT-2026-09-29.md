# Проверка KODA — 29 сентября 2026

## Исправления

- Фоновая загрузка больше не сбрасывает состояние загрузки уже открытых разделов. Ответ, начатый до локального редактирования, не заменяет новые данные.
- Сохранения выполняются последовательно и с задержкой 650 мс после изменения. Подтверждение старой версии не очищает очередь более свежей правки. Неуспешная запись остаётся в очереди.
- Очереди удаления задач и записей дневника сохраняются на устройстве. Повторная отправка новой записи дневника использует стабильный UUID; потерянный ответ не должен создавать дубликат. Уже отправленные неизменённые записи не пересохраняются при каждом вводе.
- Обычный фоновый опрос сокращён с одного раза в 15 секунд до одного раза в минуту. Возврат во вкладку, события realtime и повторная отправка очереди остаются отдельными механизмами.
- Тики помодоро вынесены из корневого компонента приложения: они обновляют потребителей таймера, а не все экраны.
- Текстовые формы дневника, эмоций и профиля ограничены по ширине, календарь использует доступное пространство. Правая история остаётся у правого края.
- Правая панель и панель планера учитывают системную настройку уменьшения анимации. Увеличены области нажатия части кнопок, добавлены роли и доступные названия навигации и таймера.
- Исправлено пустое состояние проектов и заметок: создать первый элемент можно из центральной части при закрытой панели.
- На узком экране логотип и строка состояния больше не вытесняют друг друга. Масштабирование страницы разрешено; увеличенный шрифт полей применяется только на сенсорных устройствах.
- Локальное сохранение заметки подтверждается после записи на устройство; облачная очередь отображается отдельно.
- Добавлены общие команды `npm test`, `npm run typecheck`. Сборка сбрасывает кэш Metro, чтобы переменные тестовой сборки не попадали в рабочую.

## Проверки

- `npm run typecheck` — успешно.
- `npm test` — 6 наборов успешно: KODA score, KODA day sync, эмоциональный дневник, помодоро, offline shell, sync coordinator.
- `npm run build:web` — успешно.
- Во встроенном браузере открыты планер, цели, проекты, заметки, обычный и эмоциональный дневник, KODA, таймер, прогресс, профиль, помощник.
- Проверены размеры 1440, 1280, 1040, 390 и 320 пикселей. На 1040 проверен календарь с открытой правой панелью; на 320 — планер и эмоциональный дневник без горизонтального переполнения.
- Созданы тестовая задача и подзадача через редактор; проверен перенос на завтра без перехода на другую дату.
- Созданы тестовая эмоциональная запись, проект и заметка. Проверены компактная история, окно подробностей и восстановление эмоциональной истории после перезагрузки.
- Таймер продолжил отсчёт после перехода по разделам и перезагрузки. Пауза остановила отсчёт.
- В журнале браузера не обнаружено ошибок JavaScript за этот проход.

Браузерные изменения выполнялись в изолированной локальной сборке без подключения к Supabase, на тестовых данных. Пользовательские записи на рабочем сайте не менялись.

## Границы проверки

Это проход по основным сценариям, а не исчерпывающее тестирование всех сочетаний действий. Конфликты двух реальных устройств и запись в рабочую базу после сетевого обрыва не проверялись сквозным тестом; для механизма очереди добавлены отдельные тесты. Мобильная проверка проведена в браузере с заданной шириной, не на физическом iPhone/Android.

Офлайн-режим требует предварительной загрузки сайта. Он не гарантирует первый запуск при блокировке домена оператором. При полной приостановке браузера ОС звук таймера может задержаться, хотя время восстанавливается по дедлайну.

У помощника пока предусмотрен шаблонный ответ в текущей реализации, а не полноценный диалог с ИИ; подключение ИИ в этот проход не добавлялось.
